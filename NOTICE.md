# Attribution and distribution

India Population Intelligence is an authored portfolio project. The package contains aggregate-only data generated for the project. Use and redistribution of project code and generated data are subject to the rights holder's terms. A project-wide open-source license has not been granted in this repository.

The simplified State/UT boundary layer is attributed to DataMeet via geoBoundaries, distributed by GeoDataViewer. The project adapts ring orientation at render time. The data carries the source's boundary conventions. [Boundary source and attribution](https://geodataviewer.com/datasets/boundaries/india-states-boundaries/) · [CC BY 2.5 India](https://creativecommons.org/licenses/by/2.5/in/)

Streamlit, DuckDB, Pandas, Plotly and their dependencies are distributed under their own licenses through the package registry. The deployment files contain dependency declarations. Package wheels are installed separately.

The records and published counts are synthetic. Results are neither official Indian statistics nor a representation of actual people.
